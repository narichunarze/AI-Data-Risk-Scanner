## 📖 Overview

AI Data Risk Scanner analyzes PDF and DOCX documents to detect sensitive information, classify risk levels, and generate anonymized versions for secure sharing and compliance.

## ✨ Features

- Sensitive data detection
- NLP-powered entity recognition
- Automated risk classification
- Data anonymization
- Analytics dashboard
- Audit trail storage

## 🏗 Architecture

```text
User
 ↓
Frontend (HTML/CSS/JS)
 ↓
FastAPI API
 ↓
Extractor → Detector → Classifier → Anonymizer
 ↓
SQLite Database
```

## 🛠 Technology Stack

- Python 3.10+
- FastAPI
- spaCy
- SQLite
- PyMuPDF
- python-docx
- HTML/CSS/JavaScript

## 📈 Impact

- Protects sensitive information
- Supports compliance initiatives
- Creates privacy-safe AI datasets
- Reduces manual document review effort
